Elytra Fluid Flight 是一個為 Minecraft Java 26.2 而設的小型 Fabric 模組。原版鞘翅一碰到水或岩漿就會收起；裝上這個模組後，你可以繼續飛行，沿用原版滑翔物理，再疊上一層可自行調整的額外阻力。

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-HK.md)

## 功能

- **在水和岩漿中滑翔。** 滑翔時進入液體，飛行會繼續，而不是立即收翼。
- **游泳與滑翔互不相干。** 在水底按住衝刺即進入原版游泳狀態：移動完全交回水的物理（游泳、下潛、上浮），跳躍只作上浮、不會展開鞘翅。兩個狀態不會重疊，放開衝刺即繼續滑翔。
- **液體中也能起飛。** 先浮離水底或岩漿底部，再按跳躍展開鞘翅。
- **煙火照常可用。** 滑翔時右鍵煙火火箭即可推進，水中和岩漿中一樣有效，並保留原版的消耗量與推進時間。
- **阻力可調。** 自行決定水和岩漿的阻力強度。
- **可選的耐火要求。** 可要求玩家必須擁有耐火效果，才能在岩漿中滑翔。
- **原版規則不變。** 鞘翅耐久度、着地收翼、懸浮效果與梯子限制，以及溺水、岩漿灼傷和爆炸傷害，全部照舊生效。

## 環境要求

| | |
| --- | --- |
| Minecraft | Java 版 **26.2** |
| 模組載入器 | **Fabric Loader 0.19.5** 或更新（驗證版本為 0.19.5） |
| Java | **25** 或更新 |
| 其他模組 | 無需安裝——不用 Fabric API、Cloth Config 或 Mod Menu |

這是 Fabric 模組，不適用於 Forge、NeoForge、基岩版或其他 Minecraft 版本。

## 安裝

**單人遊戲（只裝客戶端）**

1. 為 Minecraft 26.2 安裝 Fabric Loader 0.19.5 或更新版本。
2. 把 `elytra-fluid-flight-<版本>+mc26.2.jar` 放入遊戲實例的 `mods` 資料夾。
3. 啟動 Minecraft 即可，沒有額外依賴。

請勿安裝檔名以 `-sources.jar` 結尾的檔案，那個是給開發者用的。

**多人遊戲**

- 客戶端和伺服器**都**必須安裝本模組。
- 兩邊請使用相同的設定。本版本不會自動同步設定。

## 使用說明

- 展開鞘翅飛進水或岩漿：滑翔會繼續，速度由你的設定決定。
- 想游泳？在水底按住衝刺，眼睛要在水裡。這樣會進入原版游泳狀態：移動交回水的物理（游泳、下潛、上浮），跳躍只作上浮、不會展開鞘翅；放開衝刺即繼續滑翔。這一條只適用於水，在岩漿裡衝刺不會有任何改變。
- 已經在液體中？先游離底部方塊，再按跳躍展開鞘翅。
- 滑翔時右鍵煙火即可推進，水中和岩漿中一樣有效。
- 着地會收翼，與原版一致。

## 設定

首次啟動時會自動建立設定檔：

- 客戶端：`.minecraft/config/elytra_fluid_flight.json`
- 伺服器：`<伺服器資料夾>/config/elytra_fluid_flight.json`

```json
{
  "waterSpeedMultiplier": 0.6,
  "lavaSpeedMultiplier": 0.35,
  "lavaRequiresFireResistance": false
}
```

| 設定項 | 預設值 | 說明 |
| --- | --- | --- |
| `waterSpeedMultiplier` | `0.6` | 水中滑翔的阻力強度：數值越小，水越黏稠。詳見下方說明。 |
| `lavaSpeedMultiplier` | `0.35` | 同上，作用於岩漿——數值越小，岩漿越黏稠。 |
| `lavaRequiresFireResistance` | `false` | 改為 `true` 後，必須擁有耐火效果才能在岩漿中滑翔；效果結束時岩漿滑翔會中止。 |

幾點須知：

- 有效範圍是 `0 < 數值 <= 1`。這是阻力強度：數值越小液體越黏稠，`1.0` 與原版空中物理完全一致。
- 為求穩定，每個遊戲刻只按該強度的一成施加阻尼，所以 `0.6` 大約等於每刻保留 96% 速度、`0.35` 大約 93.5%。液體明顯更黏稠，但仍然飛得動；若每刻都把整個速度乘以該數值，半秒內就會幾乎停頓。
- 液體交界同時偵測到水和岩漿時，採用岩漿的設定。
- 數值超出範圍會回退到該項預設值並寫入日誌。檔案損毀時會使用預設值，並保留你的原檔案，方便自行修正。
- 設定在啟動時讀取，修改後請重新啟動客戶端或伺服器。多人遊戲中兩邊請保持一致。

## 本模組不會改動的部分

- 鞘翅耐久度、着地收翼、懸浮效果、梯子限制，以及原版「需要一件可用鞘翅」的檢查。
- 溺水、岩漿灼傷和煙火爆炸傷害。本模組不提供水中呼吸，也不提供耐火效果。
- 游泳：在水底按住衝刺時，一律使用原版水的物理，包括浮力和游泳姿態。
- 煙火火箭本身：沒有取代任何物品或實體。原版在滑翔狀態下本來就會推進玩家，所以在液體中自然同樣有效。

## 相容性

- 修改玩家移動或鞘翅物理的模組，以及伺服器端反作弊外掛，可能需要另外做相容性測試。
- 不依賴 Fabric API。以 Fabric API 為基礎的模組包一般沒有問題，只要在需要的一邊都安裝本模組。
- 已在真實 Minecraft 26.2 的 Fabric 伺服器上，用實際的水和岩漿方塊通過 52 項自動檢查。圖形客戶端的手動操控、模組包組合、流動液體和氣泡柱，仍建議你在自己的環境試一次。

## 從原始碼建置

需要 JDK 25。專案內附 Gradle Wrapper，首次建置會下載相依項目。

```sh
# macOS / Linux
chmod +x gradlew
./gradlew build
```

```bat
:: Windows
gradlew.bat build
```

產物位於 `build/libs/elytra-fluid-flight-<版本>+mc26.2.jar`。

整合測試會啟動一個真實的 Minecraft 26.2 + Fabric Loader 0.19.5 伺服器，在臨時測試世界中執行；伺服器只綁定 `127.0.0.1`，使用動態連接埠，完成後自動關閉，不會動到你現有的存檔。請在已閱讀並接受 Minecraft EULA 的前提下執行：

```sh
./gradlew runIntegrationTest -PacceptMinecraftEula=true
```

結果會寫入 `run-test/test-result.txt`。
