# Elytra Fluid Flight

**在水里、在岩浆里，继续滑翔，继续用烟花推进。**

Elytra Fluid Flight 是一个为 Minecraft Java 26.2 制作的小型 Fabric 模组。原版鞘翅一碰到水或岩浆就会收起来，装上这个模组后你可以继续飞行，使用原版滑翔物理，并叠加一份可自行调整的额外阻力。

[English](README.md) | [简体中文](README.zh-CN.md)

## 功能

- **在水和岩浆中滑翔。** 滑翔状态进入液体后继续保持飞行，而不是立刻收翼。
- **液体中也能起飞。** 在水底或岩浆底部先浮起来离开地面，再按跳跃键展开鞘翅。
- **烟花照常可用。** 滑翔时右键烟花即可推进，水中和岩浆中同样有效，保留原版的消耗与飞行时间。
- **阻力可调。** 自行决定在水中和岩浆中每个游戏刻保留多少速度。
- **可选的耐火要求。** 可以要求玩家必须拥有耐火效果才能在岩浆中滑翔。
- **原版规则不变。** 鞘翅耐久、落地收翼、漂浮效果与梯子限制，以及溺水、岩浆灼伤和爆炸伤害，全部照旧生效。

## 环境要求

| | |
| --- | --- |
| Minecraft | Java 版 **26.2** |
| 模组加载器 | **Fabric Loader 0.19.5** 或更高（验证版本 0.19.5） |
| Java | **25** 或更高 |
| 其他模组 | 无需安装 Fabric API、Cloth Config 或 Mod Menu |

这是 Fabric 模组，不适用于 Forge、NeoForge、基岩版或其他 Minecraft 版本。

## 安装

**单人游戏（只装客户端）**

1. 为 Minecraft 26.2 安装 Fabric Loader 0.19.5 或更高版本。
2. 把 `elytra-fluid-flight-<版本>+mc26.2.jar` 放进游戏实例的 `mods` 文件夹。
3. 启动游戏，不需要额外依赖。

不要安装文件名以 `-sources.jar` 结尾的那个文件，它是给开发者看的。

**多人游戏**

- 客户端和服务器**都要**安装本模组。
- 两边请使用相同的配置。当前版本不会自动同步配置。

## 使用说明

- 展开鞘翅飞进水里或岩浆里：滑翔继续，速度由你的配置决定。
- 已经在液体中？先浮起来离开底部方块，再按一次跳跃键展开鞘翅。
- 滑翔时右键烟花即可推进，水中和岩浆中一样有效。
- 落地会收翼，与原版一致。

## 配置

首次启动时会自动生成配置文件：

- 客户端：`.minecraft/config/elytra_fluid_flight.json`
- 服务器：`<服务器目录>/config/elytra_fluid_flight.json`

```json
{
  "waterSpeedMultiplier": 0.6,
  "lavaSpeedMultiplier": 0.35,
  "lavaRequiresFireResistance": false
}
```

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `waterSpeedMultiplier` | `0.6` | 在水中每个游戏刻保留的原版鞘翅速度比例。 |
| `lavaSpeedMultiplier` | `0.35` | 同上，作用于岩浆。 |
| `lavaRequiresFireResistance` | `false` | 改为 `true` 后，必须拥有耐火效果才能在岩浆中滑翔；效果结束时岩浆滑翔会中止。 |

几点说明：

- 有效范围是 `0 < 数值 <= 1`。每个游戏刻，原版鞘翅物理算出的速度向量会乘以该数值。它不是固定的最高速度比例，原版空气阻力依旧存在。
- 数值越小阻力越大。默认的 `0.6` 和 `0.35` 减速很快，适合配合烟花使用；想要更长时间的惯性滑翔，可以试试 `0.9` 和 `0.8`。
- 液体交界处同时检测到水和岩浆时，采用岩浆的设置。
- 数值超出范围时会回退到该项默认值并记录日志。文件格式损坏时使用默认配置，且不会覆盖你的原文件，方便自行修正。
- 配置在启动时读取，修改后请重启客户端或服务器。多人游戏中两边请保持一致。

## 本模组不改动的部分

- 鞘翅耐久、落地收翼、漂浮效果、梯子限制，以及原版“需要一件可用鞘翅”的检查。
- 溺水、岩浆灼伤和烟花爆炸伤害。本模组不提供水下呼吸，也不提供耐火效果。
- 烟花本身：没有替换任何物品或实体。原版在滑翔状态下本来就会推进玩家，因此液体中自然也能生效。

## 兼容性

- 修改玩家移动或鞘翅物理的模组，以及服务器反作弊插件，可能需要单独做兼容性验证。
- 不依赖 Fabric API。基于 Fabric API 的整合包一般没问题，只要在需要的一侧都安装本模组。
- 已在真实 Minecraft 26.2 的 Fabric 服务端上用实际的水和岩浆方块跑通 47 项自动检查。图形客户端的手动操控、整合包组合、流动液体和气泡柱仍建议你在自己的环境里试一下。

## 从源码构建

需要 JDK 25。项目自带 Gradle Wrapper，首次构建会下载依赖。

```sh
# macOS / Linux
chmod +x gradlew
./gradlew build
```

```bat
:: Windows
gradlew.bat build
```

产物位于 `build/libs/elytra-fluid-flight-<版本>+mc26.2.jar`。

集成测试会启动一个真实的 Minecraft 26.2 + Fabric Loader 0.19.5 服务端，在临时测试世界中运行，只监听 `127.0.0.1` 并使用动态端口，完成后自动退出，不会使用你现有的存档。仅在你已阅读并接受 Minecraft EULA 的前提下运行：

```sh
./gradlew runIntegrationTest -PacceptMinecraftEula=true
```

结果写入 `run-test/test-result.txt`。
